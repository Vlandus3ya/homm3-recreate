# Recreate Open Resources — initial specification

## Purpose
This folder is the starting point for a Recreate-owned asset pack. The goal is to make a small original fantasy strategy-game data set that can eventually be distributed without requiring the proprietary Heroes III art, audio, maps, or campaign files.

## Current status
This is a specification and project scaffold only. It does **not** yet contain a complete playable data set, and VCMI cannot be expected to load a game from this document alone.

## Asset work planned
- Original terrain tiles and adventure-map objects.
- Original town and creature artwork.
- Original interface elements and icons.
- Original sound effects and music, or assets with licenses that explicitly permit redistribution and modification.
- A small tutorial map and test scenario authored from scratch.
- Mod metadata and localization files in the format supported by the exact VCMI revision pinned by this repository.

## Rules
1. Do not copy or trace Heroes III proprietary assets.
2. Do not include extracted game files, campaign files, videos, music, fonts, or sound effects from commercial game installations.
3. Record the author, source, and license for every asset.
4. Prefer CC0 or CC BY 4.0 assets when external assets are used; retain all required attribution and notices.
5. Validate the pack against the pinned VCMI version before describing it as compatible or playable.

## First playable milestone
A minimal original scenario with a small set of original terrain, objects, heroes, creatures, and interface assets. Until that milestone is complete and tested, the pack remains a development scaffold.

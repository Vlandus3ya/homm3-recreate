Heroes of Might and Magic III: Recreate
Windows package notes

The installed layout places the VCMI runtime in:
  Game Engine\vcmi\

The Recreate front ends are installed at the application root:
  h3r.exe
  Modding Studio.exe

The installer creates these project folders:
  Game Engine\vcmi\data
  Game Engine\vcmi\h3mmaps
  Game Engine\vcmi\vmapmaps
  Game Engine\vcmi\Video
  Game Engine\vcmi\sounds
  Profile
  settings
  InternetIpConnections
  Bots

The installer does not contain proprietary original Heroes III game data.
During setup, users may select their own lawful Heroes III folder containing
Data and Maps. Data is copied to Game Engine\vcmi\data; Maps is copied to
Game Engine\vcmi\h3mmaps. VIDEO.VID and Heroes3.snd are also copied into the
dedicated Video and sounds folders. Existing files are not overwritten.
If import is skipped, the folder structure is still created, but game resources
will be missing until the user supplies them.

The vmapmaps folder is intentionally not populated by renaming .h3m files.
Maps must be genuinely converted to .vmap using VCMI Map Editor.

RegisterSOD and hmm3sod.reg are not part of the Recreate setup.

The VCMI runtime supplies the engine, supported game rules/mechanics, and its
available AI implementations. Actual maps, campaigns, and assets available in
a particular installation depend on the game data and VCMI-compatible mods
installed by the user.

Do not download or install unofficial game-data packs from untrusted sources.
Do not commit or redistribute proprietary Heroes III resources in this public
repository or its public build artifacts.
